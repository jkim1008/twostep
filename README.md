# Two Step

An iOS app for managing money as a household of two — shared transactions, budgets, and savings goals with per-partner attribution.

## Stack

- Swift 6 / SwiftUI, iOS 18+, MVVM with `@Observable`
- `TwoStepCore` — pure Swift package holding all money math and domain logic (no framework imports), unit-tested with Swift Testing
- Xcode project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) — `TwoStep.xcodeproj` is never committed or hand-edited

## Setup

```
brew install xcodegen swiftlint
xcodegen generate
open TwoStep.xcodeproj
```

## Tests

```
swift test --package-path TwoStepCore        # core logic tests (fast, no simulator)
```

UI smoke tests run via the TwoStep scheme (⌘U) or CI.

## Workflow

All changes land via pull request with green CI. `main` is protected — no direct pushes.
